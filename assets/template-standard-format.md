# V3终极格式标准模板

## 场景格式

```markdown
[SCENE 001][00:00:00–00:01:20] INT. 场景名称 - DAY

## 场景描述
（空间锚点、初始状态、氛围来源）

---
```

## 镜头格式

```markdown
### 镜头 1

（景别-视角-运镜）（重点：唯一重点内容）

#### 画面描述层（绝对客观物理）
[角色名]在[场景位置]，[具体动作描述]。
[角色名]的[身体部位][具体运动轨迹]。
[环境/道具][物理状态变化]。
（如有碰撞或大动作）[特效反馈指令]。

#### SFX / UI / 屏显
（如有）

---
```

## 台词格式

```markdown
**角色名**
（情绪状态、表演指导、语气说明）
"台词内容，可以使用代词。"
```

## 完整示例

```markdown
[SCENE 003][00:02:15–00:02:45] INT. 废弃工厂 - NIGHT

## 场景描述
废弃工厂内部。中央有一个直径5米的塌陷坑，边缘参差不齐。
左侧墙壁上挂着破损的经幡，在微风中轻轻摆动。
右上方有破损的天窗，月光和蓝色警示灯交替照亮场景。

---

### 镜头 1

（中景-平视-固定）（重点：胶布的安全着陆状态）

#### 画面描述层
胶布背部着地，四肢平摊在金属地面上。胶布的右手先触碰头部，随后缓慢下移触碰双腿。胶布胸口大幅度起伏，呼吸急促。塌陷坑边缘的灰尘因震动而轻微飘落。经幡停止摆动两秒后恢复。

---

### 镜头 2

（近景-微俯-缓慢推近）（重点：劫后余生的庆幸感）

#### 画面描述层
胶布面部特写。额头有细密的汗珠。嘴角先微微颤抖，然后上扬。胶布双眼紧闭，然后慢慢睁开。

**胶布**
（长长地吐出一口气，冷汗直流，语气里带着大难不死的极度庆幸）
"还好……我没摔成截图。"

---

### 镜头 3

（全景-仰视-轻微摇晃）（重点：上方威胁的存在）

#### 画面描述层
镜头从胶布视角向上看。天窗外有一个巨大的黑色轮廓缓慢移动。轮廓边缘有微弱的蓝色脉冲光。天窗玻璃出现细微裂纹。（镜头轻微震动）。裂纹以脉冲光的位置为中心，向四周蔓延。

**胶布**
（声音压低，紧张）
"……它还在上面。"

---
```

## 资产连续性补写原则

`standardized-script` 仍然保持干净剧本格式，不新增资产账本字段。

Stage 4.5 的低风险连续性补写可以进入 `画面描述层`，例如：

- 已折断的道具后续仍写成断裂状态
- 已受伤或沾污的角色后续保持可见状态
- 已破坏的场景后续保留碎片、血迹、烟尘、水火等留痕

中风险和高风险连续性建议不得直接写入标准稿，应保留在 `asset-continuity-ledger` 中供编剧确认。

## 格式要点速查

| 元素 | 规范 |
|------|------|
| 场景标题 | `[SCENE XXX][时间码] INT./EXT. 场景名 - DAY/NIGHT` |
| 镜头标题 | `（景别-视角-运镜）（重点：xxx）` |
| 画面层 | 无代词、纯物理、去意图 |
| 台词层 | **角色名** + (情绪指导) + "台词" |
| 物理反馈 | 碰撞必加 `(镜头震动)` + 粒子特效 |
| 负向约束 | 写明 `不出现/不新增/不改变` |

## 景别术语

| 景别 | 描述范围 |
|------|----------|
| 特写 | 面部/手部/物品细节 |
| 近景 | 胸部以上 |
| 中景 | 膝盖以上 |
| 全景 | 全身+少量环境 |
| 远景 | 主体在环境中较小 |
| 大远景 | 环境为主，主体很小 |

## 视角术语

| 视角 | 含义 |
|------|------|
| 平视 | 与主体视线持平 |
| 俯视 | 从上往下看 |
| 仰视 | 从下往上看 |
| 微俯 | 轻微俯视 |
| 微仰 | 轻微仰视 |

## 运镜术语

| 运镜 | 含义 |
|------|------|
| 固定 | 镜头不动 |
| 推 | 镜头向前移动 |
| 拉 | 镜头向后移动 |
| 摇 | 镜头左右转动 |
| 移 | 镜头水平移动 |
| 跟拍 | 跟随主体移动 |
| 环绕 | 围绕主体旋转 |
